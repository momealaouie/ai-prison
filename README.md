# AI Prison

AI Prison is a playful, pixel-inspired control center for training and delegating work to AI agents.

The first vertical slice includes:

- A top-down 1920×1080-style prison world
- A playable director character
- Autonomous agent characters with departments and statuses
- Click-to-inspect agent cards
- Fullscreen mode and a real-time activity log placeholder

## Run locally

```bash
npm install
npm run dev
```

This prototype uses procedural placeholder art. The visual direction is colorful, top-down, grid-based pixel art inspired by classic management games; original art assets will be added later.
